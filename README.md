# Project:  customer-portal-backend

### 📝 Overview
This repository outlines my 7-month engagement as a Senior Developer for Toyota, collaborating with a 20-person team. The project focused on developing and maintaining a portal designed to provide customers with information about new features. 

*Note: Proprietary source code is omitted. This document serves as a technical case study.*

### 🏗️ Responsibilities & Contributions
*   **Feature Development:** Handled the implementation of Change Requests (CRs) to enhance the portal's functionality.
*   **System Maintenance:** Executed necessary bug fixes to ensure application stability and a smooth customer experience.
*   **Cloud Operations:** Responsible for monitoring the application's infrastructure using AWS CloudWatch.

### 🛠️ Technology Stack
*   **Core Language:** Java
*   **Frameworks:** Spring MVC, Hibernate
*   **Database:** MySQL
*   **Cloud & OS:** AWS (CloudWatch), Windows
*   **Tools:** Eclipse, SOAP UI, Postman, JIRA, Git
